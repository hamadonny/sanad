# Apple — App Privacy ("nutrition label") answers

Tracking: **No** (no data used to track across other companies' apps or websites; no ads SDK).

| Data type                                                             | Collected | Linked to the user | Purpose                                                            |
| --------------------------------------------------------------------- | --------- | ------------------ | ------------------------------------------------------------------ |
| Contact info → Name                                                   | Yes       | Yes                | App functionality (identity verification, contracts)               |
| Contact info → Phone number                                           | Yes       | Yes                | App functionality (sign-in, reminders)                             |
| Contact info → Physical address                                       | Yes       | Yes                | App functionality (identity verification)                          |
| Financial info → Other financial info (payment history, amounts owed) | Yes       | Yes                | App functionality                                                  |
| User content → Photos (Civil ID, selfie)                              | Yes       | Yes                | App functionality (identity verification)                          |
| User content → Other (support messages)                               | Yes       | Yes                | App functionality / customer support                               |
| Identifiers → User ID                                                 | Yes       | Yes                | App functionality                                                  |
| Usage data → Product interaction                                      | Yes       | **No**             | Analytics (anonymous daily counts; user can switch off)            |
| Diagnostics → Crash data                                              | Yes       | **No**             | App functionality (scrubbed of personal data)                      |
| Sensitive info (government ID number)                                 | Yes       | Yes                | App functionality — declare under "Other data types" if Apple asks |

Not collected: location, contacts, browsing history, search history, health, audio, payment
card numbers (handled by the licensed gateway in Phase 7), advertising data.
